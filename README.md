# DevTool

All-in-one browser-based developer utility toolkit. Fast, local, no server-side processing — everything runs in the browser.

## Tools

| Tool | Description |
|------|-------------|
| Diff Checker | Compare two text blocks with line-level changes and counts |
| Epoch Converter | Convert Unix timestamps to readable local and UTC dates |
| HMAC Generator | Generate keyed hashes with SHA-1, SHA-256, SHA-384, or SHA-512 |
| JSON Formatter | Beautify, minify, and validate JSON with 2 or 4 spaces |
| JWT Decoder | Decode JWT headers and payloads locally without verification |
| Lorem Ipsum Generator | Generate placeholder paragraphs, sentences, or words |
| Regex Tester | Test regular expressions, flags, matches, indexes, and groups |
| Secret Key Generator | Generate cryptographic random keys in hex or base64 |
| UUID Generator | Create one or many browser-generated UUID v4 values |
| Word Counter | Measure words, characters, lines, sentences, bytes, and reading time |

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript (strict)
- **Icons**: Lucide React
- **Styling**: CSS (no framework)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run typecheck` | Run TypeScript type checking |
